Sharer für Windows herunterladen

Du brauchst den Sharer nur, wenn du deinen eigenen Bildschirm teilen willst — wer Hilfe leistet, öffnet einfach diese Seite und tippt den Code ein.

  • Keine Installation — Datei doppelklicken, läuft.
  • Keine Daten bei uns — kein Konto nötig, Bildschirm-Daten fließen direkt P2P.
  • DSGVO-konform — Server in Deutschland, keine Tracker, keine IPs im Klartext.
  • Open Source (MIT) — Quellcode auf GitHub einsehbar und auditierbar.
Sharer für Windows (.exe) Setup-Installer (mit WebView2) Alle Releases

Standalone-.exe (~30 MB) für Windows 10/11 mit vorinstalliertem WebView2 — auf modernen Systemen Standard. Falls beim Start eine Fehlermeldung erscheint, nutze den Setup-Installer (~150 MB), der die WebView2-Runtime mitinstalliert. Linux-Pakete (Debian/Ubuntu, Fedora, Arch) findest du auf der eigenen Download-Seite; macOS kommt später.

Warum Auffi?

🔒 Ende-zu-Ende verschlüsselt

WebRTC mit DTLS-SRTP. Der Server vermittelt nur den initialen Handshake — Bildschirminhalte, Eingaben und Dateien fließen direkt zwischen den Browsern.

🇩🇪 Server in Deutschland

Hosted auf IONOS-VPS in Frankfurt. DSGVO-konform, keine US-Cloud, keine Drittanbieter-Tracker, keine Google Fonts.

🆓 Open Source (MIT)

Vollständiger Quellcode auf GitHub. Selbst hosten, auditieren oder forken — Backend, Viewer und Sharer sind dokumentiert.

👤 Kein Konto nötig

9-stelliger Code, Verbinden, fertig. Konto nur für Unattended Access — also wenn du regelmäßig dieselben Geräte verbindest.

⚠ Noch 2 Min Relay-Zeit übrig — Premium kommt bald
