Quick Assist alternative: Auffi compared head-to-head

Microsoft Quick Assist is handy as long as both sides run Windows — it is free and already part of the system. But the person helping has to sign in with a Microsoft account, and there is no everyday Quick Assist for Mac or Linux. With Auffi the helper just opens auffi.app in a browser and types a 9-digit code — on any operating system, no installation, no account. The person sharing their screen installs a small sharer app for Windows or Linux.

When Auffi is the better choice

  • The person helping is not on a Windows PC — say on a Mac, on Linux, or on a borrowed computer.
  • Nobody should have to create or sign in to a Microsoft account for a quick bit of help.
  • The screen in question runs Linux.
  • Quick Assist is blocked or uninstalled at your company, and you still need a way to help.
  • You want to self-host the service, or you care about servers in Germany and open code.

When Quick Assist is the better choice

  • Both sides run Windows and the helper already has a Microsoft account.
  • The person sharing should install nothing at all — Quick Assist is usually already on current Windows PCs.
  • You want to draw on the screen (annotations) to point something out.
  • Microsoft Support is helping you directly — Quick Assist is the tool they use.

Quick Assist alternative: where the difference shows up day to day

Quick Assist and Auffi solve the same job: someone needs help at their computer right now, and a second person should see the screen and take over if needed. Both use a short code you read out over the phone, and with both the person at the shared computer confirms every connection. The difference lies in what each side has to bring.

Who has which device. Quick Assist assumes Windows on both ends. Microsoft only hands out the Mac version as part of its own support cases. If you are on a MacBook and want to help a relative on her Windows laptop, Quick Assist will not get you there. With Auffi the helping side is a browser tab — Windows, macOS or Linux.

Who has to sign in. With Quick Assist the helper signs in with a Microsoft account or a work account (Entra ID); according to Microsoft, a local Active Directory account is not enough. For family help that is often where things stall: forgotten password, two-factor code on the other phone. Auffi needs no account at all for ad-hoc help.

Who has to install something. Here Quick Assist has a real advantage: on current Windows PCs it is usually already there (otherwise it comes from the Microsoft Store). With Auffi the person sharing their screen installs a small sharer app for Windows or Linux. In return, the helping side stays install-free.

When Quick Assist is blocked

Over the past few years Quick Assist has repeatedly been abused in scam calls: attackers pose as IT support and talk victims into starting a session. Microsoft therefore advises organizations to disable or uninstall Quick Assist if they use a different tool. Many companies have blocked Quick Assist by now.

If you still need to help, you need a Quick Assist alternative that is not tied to Microsoft services. Auffi can also run entirely on your own infrastructure: with Docker Compose the whole service, including signaling and TURN, runs on your own server. The ground rule is the same for every tool: never give access to your computer to anyone you did not ask for help yourself. Auffi shows a confirmation dialog before every ad-hoc session for exactly that reason.

Frequently asked questions

What is the difference between Auffi and Microsoft Quick Assist?

Quick Assist is built into Windows and works only between two Windows PCs; the person helping has to sign in with a Microsoft account. With Auffi the helper just opens auffi.app in a browser, on any operating system and without an account. The person sharing their screen installs a small sharer app for Windows or Linux.

Does Quick Assist work on a Mac or on Linux?

According to Microsoft, Quick Assist for macOS is only available during interactions with Microsoft Support, not for general use. There is no Linux version. With Auffi the helper can use any current browser, including on a Mac or on Linux; the shared screen can be Windows or Linux.

Does Auffi need an account?

Not for ad-hoc help. The helper types a 9-digit code and the person sharing confirms the connection. You only need an account for unattended access to your own paired devices.

Why do some companies block Quick Assist?

Quick Assist has repeatedly been abused in scam calls where attackers pose as IT support. Microsoft recommends that organizations disable or uninstall Quick Assist if they use a different remote support tool. Where Quick Assist is blocked, you need an alternative.

Is Auffi free like Quick Assist?

Yes. Auffi is free for personal and commercial use and open source under the AGPL-3.0. If you prefer, you can run all of Auffi on your own server with Docker Compose.
