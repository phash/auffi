Sharer herunterladen

Windows Linux

Version 0.7.6 · Windows 10/11, Debian 13+, Ubuntu 24.04+, Fedora 42+. Danach den Code an den Helfer durchgeben.

Der Mensch am geteilten Rechner bestätigt jede Verbindung. Danach läuft das Bild direkt zwischen beiden Rechnern, DTLS-SRTP-verschlüsselt.

Warum Auffi

Helfen ohne Konto, mit offenem Quelltext

Der Helfer braucht nur einen Browser. Wer seinen Bildschirm teilt, startet den Sharer und klickt „Verbinden zulassen“. Der Server steht in Deutschland, der Code ist AGPL.
